## Projects

### ASR Caption Error Analysis
*Python · OpenAI Whisper · jiwer · pandas · Hugging Face Datasets*

[Repository](https://github.com/ifoslien/asr-caption-error-analysis)

- Transcribed **10 earnings calls** with Whisper and scored them against human reference transcripts
- Found that about **a fifth of apparent errors were formatting differences** and not recognition mistakes
- Showed that many deletions were **dropped repetitions**, which reflects a captioning style gap more than a recognition failure

### Live Social Media Language Dashboard
*Python · Bluesky Jetstream · lingua · Dash · Plotly · GitHub Actions*

[Repository](https://github.com/ifoslien/bluesky-language-dashboard)

- Samples public posts **every hour** and runs automatic language identification on each one
- Compares the **language a user declares with the language they actually write in**

### Linguistic Style Dashboard
*Python · NLTK · VADER · textstat · Dash · Plotly*

[Repository](https://github.com/ifoslien/book-linguistics-dashboard)

- Compares **seven classic novels** on vocabulary richness, sentence length, reading level and sentiment
- Includes a **book similarity recommender** built on the NLTK Gutenberg corpus
